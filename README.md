# Dynamic Avian Constraint Layer for UTM Systems

**Open Technical Specification v1.0**  
September 2026  
Status: Open Technical Contribution (No Commercial Interest)

This repository contains a complete technical specification for a **dynamic wildlife constraint layer** intended for Unmanned Traffic Management (UTM) / U-space systems.

The core idea is a relay chain of UAS equipped with thermal imaging and lightweight CNN detection that continuously tracks bird flocks along a corridor and generates machine-readable dynamic geo-fences (UVRs / UREPs) that can be fed directly into the UTM network.

### Key Features
- Handoff protocol with failure handling, splitting and merging logic
- Geo-fence generation rules and JSON data formats
- Test scenarios with measurable success criteria
- Explicit regulatory mapping to EASA U-space Regulation (EU) 2021/664 and NASA UTM ConOps v2.0
